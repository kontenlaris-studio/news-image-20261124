## Run it

```sh
python3 main.py
```

The poster is rendered procedurally by `render_artwork.py` (pure Python standard library: a 5x7 bitmap font and a hand-rolled PNG encoder) into `artwork.png`, and `main.py` publishes it to `/output/entry.png`.
